Google ranks pages for specific search queries. Every keyword below represents real people searching for something you sell. Use these naturally in your page titles, descriptions, headings, and product copy.

## Where to use these keywords

1. **Page `<title>`** — most important signal. One primary keyword per page.
2. **Meta description** — influences click-through rate; include 1-2 keywords naturally.
3. **H1 heading** — one per page, include primary keyword.
4. **H2/H3 subheadings** — secondary keywords.
5. **Product description copy** — write naturally; don't stuff.
6. **Image `alt` attributes** — describe the image using relevant keywords.
7. **URL slugs** — `/products/arab-card-game-original` beats `/products/product-1`.
8. **Blog post titles** — target Tier 2 and Tier 3 keywords here.
