# SEO Implementation Checklist
## The Arab Card Game — Organic Visibility for Arab Diaspora

---

## PHASE 1: Technical SEO (Do First — Highest Impact)

### On-Page Fundamentals
- [ ] Add meta tags from `meta-tags-template.html` to every page `<head>`
- [ ] Add JSON-LD structured data from `structured-data.json` to homepage and product pages
- [ ] Upload `sitemap.xml` to website root and submit to Google Search Console
- [ ] Upload `robots.txt` to website root
- [ ] Set up Google Search Console (search.google.com/search-console)
- [ ] Verify site ownership in Google Search Console
- [ ] Set up Bing Webmaster Tools (same process, more Middle East reach)
- [ ] Enable SSL / HTTPS (if not already)
- [ ] Check Core Web Vitals score in Search Console — fix any "Poor" ratings
- [ ] Compress all product images (use squoosh.app — free)
- [ ] Add descriptive `alt` text to ALL images including Arabic translation

### URL Structure
- [ ] Ensure product URLs are clean: `/shop/arab-card-game-1` not `/shop?id=123`
- [ ] Add canonical tags to prevent duplicate content
- [ ] Set up 301 redirects for any old URLs

## PHASE 2: Content (Biggest Long-Term Driver)

### Blog Posts to Publish (in priority order)
- [ ] "Best Eid Gift Ideas for Arab Families" (seasonal — publish 6 weeks before Eid)
- [ ] "30 Things You'll Only Understand If You Grew Up Arab in the Diaspora" (viral potential)
- [ ] "The Best Party Games for Arabs" (evergreen)
- [ ] "Gift Ideas for Arab Americans / Arab Canadians / Arab Australians" (geo versions)
- [ ] "How to Host the Perfect Arab Game Night"
- [ ] "Top 10 Arab Mom Phrases Translated" (viral potential)
- [ ] Arabic-language version of homepage and key product pages

### Content Rules for Every Page
- [ ] Include primary keyword in H1 heading
- [ ] Include 2–3 secondary keywords naturally in body text
- [ ] Write meta descriptions that include keywords AND emotional hook
- [ ] Add internal links between blog posts and product pages
- [ ] Include at least one image with descriptive alt text per post
- [ ] Aim for 600–1500 words per blog post

## PHASE 6: Arabic-Language SEO

### Why It Matters
Arabic is the 5th most-spoken language online. Arab diaspora members frequently search in Arabic, especially older generations and first-generation immigrants.

### Actions
- [ ] Add Arabic translation of homepage (`/ar/` subdirectory)
- [ ] Add Arabic product descriptions
- [ ] Arabic meta tags: `<html lang="ar" dir="rtl">`
- [ ] Arabic blog post: "أفضل ألعاب للعائلات العربية" (Best games for Arab families)
- [ ] Arabic blog post: "أفكار هدايا عيد الفطر" (Eid gift ideas)
- [ ] Register on Arabic search engines: Yamli, Yandex (popular in MENA)
